# BF-044 — Academia financiera básica

**E7 · S7 · P0 · 5 SP · Dep.: BF-043**

Como principiante quiero aprender conceptos financieros justo cuando los necesito.

## Criterios de aceptación
1. Existe contenido breve para acción, ETF, riesgo, volatilidad, diversificación, rentabilidad, TER/costos, dividendos, horizonte, interés compuesto, USD/PEN y drawdown.
2. Cada concepto tiene explicación, ejemplo, por qué importa y qué no permite concluir.
3. Las fuentes educativas se identifican.
4. El contenido no presenta ejemplos hipotéticos como datos de mercado.
