# BF-046 — Comparador educativo

**E7 · S8 · P0 · 5 SP · Dep.: BF-023, BF-027, BF-042, BF-045**

Como principiante quiero comparar alternativas y entender qué diferencias importan.

## Criterios de aceptación
1. La matriz explica cada métrica en lenguaje simple.
2. Distingue costos recurrentes y costos de transacción.
3. Muestra diversificación/concentración y cobertura de datos solo cuando están verificadas.
4. Presenta compensaciones, no un ganador automático.
5. El objetivo del usuario puede mostrarse como contexto.
