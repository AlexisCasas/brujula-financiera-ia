# BF-049 — Capa verificable de históricos

**E7 · S9 · P0 · 8 SP · Dep.: BF-013, BF-014, BF-046, BF-047**

Como inversor quiero consultar rendimiento y riesgo históricos únicamente cuando la cobertura sea verificable.

## Criterios de aceptación
1. Existe un modelo versionado para métricas históricas.
2. Cada métrica registra fuente, fecha efectiva, captura, unidad, metodología y cobertura.
3. Se soportan rendimiento por periodo, volatilidad y drawdown cuando haya datos suficientes.
4. La UI marca explícitamente datos no disponibles.
5. El diseño desacopla series históricas de cualquier proveedor concreto.
6. No se descarga precio masivo ni se contrata una API sin decisión de proveedor/licencia.
