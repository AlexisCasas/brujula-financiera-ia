# BF-039 — Perfil del inversor: cuestionario versionado de tolerancia y capacidad de riesgo

**Épica:** E0 · **Sprint sugerido:** S1 · **Prioridad:** P0 · **Estimación:** 5 SP · **Dependencias:** BF-007, BF-008

## Historia de usuario

Como inversor principiante quiero responder un cuestionario sencillo que evalúe por separado mi tolerancia al riesgo y mi capacidad financiera para asumirlo, para comprender mi perfil y sus límites antes de investigar inversiones.

## Criterios de aceptación

1. El test presenta preguntas claras en español para separar capacidad financiera, tolerancia emocional, objetivo y experiencia. No solicita edad, ingreso exacto, saldo bancario ni números de cuenta.
2. El scoring es determinista, versionado y documentado. Capacidad y tolerancia se muestran separadas; el perfil global no supera la dimensión más restrictiva. Las respuestas inconsistentes o no reveladas no se fuerzan a una categoría.
3. Se muestra una explicación comprensible, factores que limitaron el resultado, fecha, versión y aviso de que es una autoevaluación educativa, no una prueba regulatoria de idoneidad ni una recomendación de inversión.
4. Cada envío guarda una fotografía inmutable; volver a responder crea otra versión y conserva la anterior. El historial se puede consultar y comparar.
5. RLS impide lectura de usuario ajeno y escritura directa. El guardado usa RPC que valida identidad y respuestas; pruebas negativas y rollback documentados.
6. Interfaz autenticada, responsive, accesible por teclado, con estados vacío/error/cargando y pruebas deterministas para bandas, límites, respuestas omitidas y contradicciones.

## Modelo de evaluación v1.0

### Capacidad financiera (0–12 puntos)
- Horizonte: menos de 1 año / 1–3 años = 0; 3–5 = 1; 5–10 / más de 10 = 2.
- Necesidad de retiro: menos de 1 año = 0; 1–3 años = 1; más de 3 años = 2.
- Fondo de emergencia: menos de 1 mes = 0; 1–3 meses = 1; más de 3 meses = 2.
- Estabilidad de ingresos: variable = 0; intermedia = 1; estable = 2.
- Dependencia del capital: esencial = 0; parcial = 1; no requerido para gastos = 2.
- Deuda de alto costo: sí = 0; no = 2.
- Bandas: 0–4 bajo; 5–8 medio; 9–12 alto.
- Si el usuario prefiere no revelar el fondo de emergencia o no está seguro sobre deuda de alto costo, la capacidad queda no determinada; no se extrapola.

### Tolerancia emocional (0–8 puntos)
- Reacción ante caídas del 10 %, 20 % y 30 %: vender todo = 0; reducir = 1; mantener o considerar aumentar = 2.
- Reacción emocional: muy ansioso = 0; preocupado pero capaz de esperar = 1; cómodo = 2.
- Bandas: 0–2 bajo; 3–5 medio; 6–8 alto.
- Se revisa coherencia: la disposición a mantener riesgo no puede aumentar al pasar de una caída del 10 % a una del 20 % o 30 %. Si las respuestas son contradictorias, no se asigna perfil global.

### Perfil global
Con ambas dimensiones completas y coherentes, el perfil global toma la categoría más baja entre capacidad y tolerancia. Objetivo y experiencia se muestran como contexto, pero no alteran la puntuación.

## Privacidad y límites

- Se guardan códigos de respuesta, puntuaciones, bandas, versión y fecha. No se solicitan importes exactos, edad, cuentas ni texto libre.
- Datos privados en Supabase con RLS de propietario único; snapshots append-only.
- Las respuestas no se envían a ChatGPT ni Claude en BF-039.
- No es prueba regulatoria de idoneidad, asesoría financiera ni recomendación de compra/venta.
- La puntuación es una regla inicial transparente para organizar la conversación; no está psicométricamente validada.
